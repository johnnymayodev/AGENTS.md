# AGENTS.md

My global agents file

## Install

### New project

From the project root, run:

```sh
curl -fsSL https://raw.githubusercontent.com/johnnymayodev/AGENTS.md/main/AGENTS.md -o AGENTS.md
```

### Existing project

If the project already has an `AGENTS.md`, append these shared defaults instead of overwriting existing instructions:

```sh
curl -fsSL https://raw.githubusercontent.com/johnnymayodev/AGENTS.md/main/AGENTS.md >> AGENTS.md
```

## Usage

Keep shared defaults in this file and project-specific commands or conventions in the project's own `AGENTS.md`.
